# Лабораторная работа №10: Сжатие методом Лемпеля – Зива (LZ77)

**Предмет:** Защита информации и надёжность информационных систем
**Тема лекции:** 07.3 «Алгоритм LZ77»
**Практикум:** ч. 1, стр. 94–102
**Программа:** `lab10/app/main.py` · **Отчёт:** `lab10/lab10.docx` (+ `lab10.pdf`)

## Задание

Разработать приложение LZ77 с изменяемыми размерами окон (словарь n1, буфер
просмотра n2), выполнить сжатие и распаковку текста объёмом несколько
килобайт, оценить скорость и эффективность при разных размерах окон.

## Реализовано

- `lz77_encode` – поиск самого длинного совпадения в словаре, выдача троек (p, q, c);
- `lz77_decode` – восстановление по тройкам (копирование фрагментов + символ);
- `token_bits` – оценка числа бит на тройку: log2 n1 + log2 n2 + 8;
- режимы: `demo`, `text`, `windows`, `all`.

## Запуск

```bash
python3 lab10/app/main.py demo     # пошаговое сжатие «молоко молоко»
python3 lab10/app/main.py text     # текст 3280 символов: сжатие/распаковка
python3 lab10/app/main.py windows  # зависимость от n1, n2
```

## Результаты

Пошагово для «молоко молоко»: `м`, `о`, `л` – литералы, затем (2,1,'к'),
(4,1,' '), (7,6) – повтор слова целиком; 6 троек на 13 символов, распаковка
совпала.

Текст 3280 символов (6120 байт), n1 = 64, n2 = 32:

| Показатель | Значение |
|---|---|
| Троек | 1409 |
| Бит на тройку | 19 |
| Объём сжатых данных | 3346 байт |
| Коэффициент сжатия | 1,83 |
| Время сжатия / распаковки | 8,8 мс / 0,2 мс |

Влияние окон (степень сжатия):

| n1 \ n2 | 8 | 16 | 32 |
|---|---|---|---|
| 16 | 1,71 | 1,61 | 1,51 |
| 64 | 2,02 | 1,93 | 1,83 |
| 256 | 6,09 | 9,45 | 13,71 |

Распаковка в ~40 раз быстрее сжатия: декодеру не нужно искать совпадения.
Рост словаря с 16 до 256 даёт восьмикратный рост степени сжатия; рост буфера
без словаря эффекта не даёт (увеличивает биты на тройку).
