# Лабораторная работа № 4. Код Хемминга — решение для букв E и N

**Предмет:** Защита информации и надёжность информационных систем
**Метод:** по практикуму ч. 1, стр. 35–47 (как в тетради: X_к = E + N, матрица H(12,4) со столбцами веса ≥ 2)

---

## 1. Исходные данные

| Символ | ASCII (hex) | Двоичный код |
|--------|-------------|--------------|
| E      | 0x45        | `0100 0101`  |
| N      | 0x4E        | `0100 1110`  |

Информационное слово — сумма символов (как в примере T + M):

```
X_к = E + N = 0100 0101 + 0100 1110 = 1001 0011
```

## 2. Параметры кода

```
k = 8                    (длина информационного слова)
r = log₂k + 1 = log₂8 + 1 = 3 + 1 = 4
n = k + r = 12
```

## 3. Проверочная матрица H(12,4)

Столбцы подматрицы P′ — двоичные записи натуральных чисел с весом ≥ 2
(3, 5, 6, 7, 9, 10, 11, 12), дополненные до r = 4 разрядов; все столбцы
различны. Справа — единичная матрица I₄:

```
H(12,4) =  0000 1111 | 1000
           0111 0001 | 0100
           1011 0110 | 0010
           1101 1010 | 0001
```

## 4. Избыточные символы (слово X_r)

Каждый проверочный бит — сумма по модулю 2 информационных бит по строке P′:

```
X_r1 = x5 ⊕ x6 ⊕ x7 ⊕ x8       = 0 ⊕ 0 ⊕ 1 ⊕ 1 = 0
X_r2 = x2 ⊕ x3 ⊕ x4 ⊕ x8       = 0 ⊕ 0 ⊕ 1 ⊕ 1 = 0
X_r3 = x1 ⊕ x3 ⊕ x4 ⊕ x6 ⊕ x7  = 1 ⊕ 0 ⊕ 1 ⊕ 0 ⊕ 1 = 1
X_r4 = x1 ⊕ x2 ⊕ x4 ⊕ x5 ⊕ x7  = 1 ⊕ 0 ⊕ 1 ⊕ 0 ⊕ 1 = 1

X_r = 0011
X_n = X_к | X_r = 1001 0011 0011
```

**d_min = 3** (все столбцы H различны и ненулевые; подтверждено перебором
всех кодовых слов) → код **исправляет 1 ошибку, обнаруживает 2**.

---

## 5. Случай 1 — 0 ошибок

```
Y_n = 1001 0011 0011        Y_r′ = Y_к · P′ = 0011
S = Y_r′ ⊕ Y_r = 0011 ⊕ 0011 = 0000
w(S) = 0  →  ошибок нет
```

## 6. Случай 2 — 1 ошибка (позиция 3)

```
Y_n = 1011 0011 0011        Y_r′ = 0101
S = Y_r′ ⊕ Y_r = 0101 ⊕ 0011 = 0110
w(S) > 0  →  есть ошибка

S = {h₃} = 0110  →  ошибка в 3-м столбце H
E_n = 0010 0000 0000

Y_n ⊕ E_n = 1011 0011 0011 ⊕ 0010 0000 0000 = 1001 0011 0011 = X_n ✓
```

## 7. Случай 3 — 2 ошибки (позиции 3 и 11)

```
Y_n = 1011 0011 0001        Y_r′ = 0101
S = Y_r′ ⊕ Y_r = 0101 ⊕ 0011 = 0100,   w(S) = 1  →  2 ошибки
```

Здесь S = 0100 совпадает с 10-м столбцом H: попытка «исправить» по синдрому
даёт неверное слово:

```
Y_n ⊕ E_n(поз. 10) = 1011 0011 0101 ≠ X_n
```

Двойную ошибку код с d_min = 3 не исправляет (t_и = ⌊(3−1)/2⌋ = 1).
При других позициях ошибок синдром может и не совпасть ни с одним столбцом
(например, ошибки в позициях 3 и 5 дают S = 1111) — исход тот же:
ошибка обнаружена, исправить нельзя.

---

## 8. Расширенный код с d_min = 4

К матрице добавляется строка общей чётности и столбец бита чётности:

```
H(12,4,4) =  те же 4 строки H + столбец 0
             снизу строка  1111 1111 1111 1
```

```
X_r_ext = 0011 0        (добавлен бит общей чётности X_n)
X_n_ext = 1001 0011 0011 0        (n = 13)
```

### Случай 4 — 3 ошибки (позиции 3, 9, 11)

```
Y_n_ext = 1011 0011 1001 0
S = 11001,   w(S) = 3
```

S ≠ 0 → ошибки **обнаружены** (d_min = 4 обнаруживает до 3 ошибок),
но **не исправлены**: t_и = ⌊(4−1)/2⌋ = 1, три ошибки коду не по силам.

Для полноты: при 1 ошибке в расширенном коде S = 01101 (3-й столбец H_ext
с единицей в строке чётности) — одиночная ошибка исправляется так же, как
в случае 2.

---

## 9. Сводка

| Параметр | Значение |
|----------|----------|
| E, N (ASCII) | `0100 0101`, `0100 1110` |
| X_к = E + N | `1001 0011` |
| k, r, n | 8, 4, 12 |
| X_r | `0011` |
| X_n | `1001 0011 0011` |
| d_min | 3 (исправляет 1, обнаруживает 2) |
| Расширенный код | n = 13, d_min = 4 (исправляет 1, обнаруживает 3) |

## 10. Проверка

Выкладки проверены программно:

- H · X_nᵀ = 0 ✓
- d_min = 3 и d_min = 4 подтверждены перебором всех кодовых слов ✓
- случай 2: Y_n ⊕ E_n = X_n ✓
- случай 3: попытка исправления даёт слово ≠ X_n ✓
