# Лабораторная работа №9: Сжатие статистическими методами (Хаффман)

**Предмет:** Защита информации и надёжность информационных систем
**Тема лекции:** 07.1 «Сжатие данных»
**Практикум:** ч. 1, стр. 84–93
**Программа:** `lab9/app/main.py` · **Отчёт:** `lab9/lab9.docx` (+ `lab9.pdf`)

## Задание

Прямое и обратное преобразования сообщения из имени и фамилии («Тимофей
Марушко») кодом Хаффмана; таблица частот строится динамически по сообщению и
по статической таблице частот русского языка; оценка эффективности по
сравнению с ASCII.

## Реализовано

- `build_tree` / `build_codes` – дерево Хаффмана и префиксные коды;
- `encode` / `decode` – кодирование в битовую строку и восстановление по дереву;
- `entropy` – энтропия источника;
- `shannon_fano` – коды Шеннона – Фано для сравнения;
- режимы: `freq`, `codes`, `codec`, `compare`, `all`.

## Запуск

```bash
python3 lab9/app/main.py freq      # частоты символов и энтропия
python3 lab9/app/main.py codes     # коды Хаффмана
python3 lab9/app/main.py codec     # кодирование и декодирование
python3 lab9/app/main.py compare   # ASCII / Хаффман / Шеннон – Фано
```

## Результаты

| Метод | Бит | Бит/символ | К ASCII, % |
|---|---|---|---|
| ASCII (8 бит) | 120 | 8,000 | 100,0 |
| Хаффман (динамическая таблица) | 57 | 3,800 | 47,5 |
| Шеннон – Фано | 57 | 3,800 | 47,5 |
| Энтропия (предел) | 56,6 | 3,774 | 47,2 |

Коды: «о» (вес 2) → `111`, «ш» → `000`, остальные 12 символов → 4-битные коды
`0010`…`1101`. Сообщение закодировано в 57 бит и восстановлено без ошибок.

Статическая таблица частот русского языка: 82 бита (68,3 % от ASCII), коды
нашлись для 13 символов из 15 (для заглавных «Т» и «М» — по 8 бит).
