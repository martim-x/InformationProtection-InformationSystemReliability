# Защита информации и надёжность информационных систем

Учебный репозиторий по дисциплине «Защита информации и надёжность информационных систем» (ИСиТ, 3 курс, осенний семестр 2026/2027).

| | |
|---|---|
| Преподаватель | проф. Урбанович П.П. |
| Лекция | пт 11.25–12.50 |
| Лабораторная | пн 9.35–11.00, ауд. 413-1 |

## Структура

- `lectures/` — лекции; основной формат — PDF, презентации оставлены только там, где PDF-версии не было.
- `labs/` — лабораторные практикумы в двух частях.
- `labN/` — решения и рабочие материалы по конкретным ЛР.
- `helper/` — дополнительные материалы:
  - `books/` — учебники и пособия;
  - `exam/` — вопросы к экзаменам;
  - `assignments/` — задания, материалы по коду Хаффмана и CTF-задачи;
  - `reference/` — справочные материалы;
  - `lab-software/` — архив программ для выполнения лабораторных.

## Безопасность

Архив в `helper/lab-software/` содержит старые исполняемые файлы Windows. Они сохранены как учебные материалы, не запускались при сортировке и должны использоваться только в изолированной среде после отдельной проверки.
