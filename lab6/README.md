# Лабораторная работа №6: Циклические коды

**Предмет:** Защита информации и надёжность информационных систем
**Тема лекции:** Лекция 05 «Циклические коды»
**Практикум:** ч. 1, стр. 57–67
**Программа:** `lab6/app/main.py`

## Задание
Вариант 1: r = 4 избыточных символа, полином G(x) = x⁴ + x + 1.
Параметры кода: n = k + r, k = 4 (информационное слово 1011), n = 8.
Построить порождающую матрицу, трансформировать в каноническую форму,
получить проверочную матрицу, вычислить Xr и Xn, промоделировать 0/1/2 ошибки,
синдром, исправление.

## Реализовано
- полиномиальная арифметика над GF(2) (poly_mod);
- систематическое кодирование через деление (encode);
- синдромное декодирование одиночной ошибки (syndrome, find позиции);
- таблица синдромов одиночных ошибок;
- моделирование 2 ошибок (ложная коррекция);
- перебор dmin по всем 2^k словам.
