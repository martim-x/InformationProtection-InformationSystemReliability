# Лабораторная работа №7: Перемежение/деперемежение данных

**Предмет:** Защита информации и надёжность информационных систем
**Тема лекции:** Лекция 06 «Перемежители»
**Практикум:** ч. 1, стр. 67–74
**Программа:** `lab7/app/main.py`

## Задание (листок)

| Величина | Значение |
|---|---|
| Информационное слово | `Xk = 101100111101001000011110100111110111` (36 бит) |
| Порождающий полином | `G(x) = x⁴ + x² + x + 1` (`0b10111`) |
| Пакет ошибок | биты **7–12** (длина пакета `b = 6`) |

Следствия, посчитанные программой, а не взятые из текста:

- `G(x) = (x + 1)(x³ + x² + 1)` делит `x⁷ + 1`, значит код циклический `(n, k) = (7, 3)`,
  `r = 4`, перебор всех 8 кодовых слов даёт `dmin = 4` → `t_испр = 1`, `t_обн = 3`;
- `Xk` на `G(x)` **не** делится (остаток `1010`) → `Xk` – информационное слово, а не кодовое;
- 36 бит = **12 слов по 3 бита** (`k = 3`), то есть ровно 12 кодовых слов по 7 бит = 84 бита
  в канале; это же число задаёт глубину перемежения.

## Реализовано

- полиномиальная арифметика над GF(2) (`poly_mod`);
- систематическое кодирование `Xk·x^r + (Xk·x^r mod G)` (`encode`);
- синдромное декодирование одиночной ошибки и таблица синдромов (`decode`, `syndrome_table`);
- блоковый перемежитель/деперемежитель: запись строками матрицы `m × n`, чтение по столбцам
  (`interleave`, `deinterleave`, `transmit`, `receive`);
- внесение пакета ошибок заданной длины в заданную/случайную позицию (`apply_burst`);
- два тракта приёма: без перемежения (`receive_plain`) и с деперемежением (`receive`).

## Результат на задании с листка

Без перемежения пакет 7–12 целиком ложится в кодовое слово 2 (5 ошибок из 7):
код с `dmin = 4` такое не исправляет, декодер делает ложное «исправление»,
сообщение восстановлено неверно (`совпадает с Xk: False`).

С перемежением (матрица `12 × 7`, чтение по столбцам) те же 6 бит попадают
в шесть разных кодовых слов – по одной ошибке на слово:


## Эксперимент

35 случайных положений пакета на каждую длину, доля полностью восстановленных
сообщений (глубина `m = 1` – передача без перемежения):

```
  b \ m |      1      2      3      4      6     12
  --------------------------------------------------
      3 |     0%    20%   100%   100%   100%   100%
      5 |     0%     0%    11%     6%   100%   100%
      6 |     0%     0%     6%     0%   100%   100%
      8 |     0%     0%     0%     3%     3%   100%
```

Вывод: перемежение не добавляет избыточности и не меняет `dmin`, но разносит
пакет по разным кодовым словам. Глубина перемежения для матрицы `m × n` равна
`m − 1` (как в примере лекции с таблицей 5 × 5), а пакет из `b` бит попадает в
разные слова при `b ≤ m = d + 1`. Ненулевые проценты при
`m < b` – случайное совпадение синдрома кратной ошибки с синдромом одиночной
(ложное исправление), а не работа метода. Плата за перемежение – задержка и
память порядка `m·n` бит на блок.
