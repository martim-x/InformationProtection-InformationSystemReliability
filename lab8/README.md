**Предмет:** Защита информации и надёжность информационных систем
**Тема лекции:** 07.2 «Блочно-ориентированное сжатие»
**Практикум:** ч. 1, стр. 75–83
**Программа:** `lab8/app/main.py` · **Отчёт:** `lab8/lab8.docx` (+ `lab8.pdf`)

## Задание (вариант 1)

Преобразование Барроуза – Уилера (BWT) для трёх блоков: имени, фамилии и слова
варианта «летоисчисление»; плюс двоичная последовательность из первых трёх
символов по кодам ASCII; сравнение времени прямого и обратного преобразований
при разной длине блока.

## Реализовано

- `rotations`, `bwt` – все циклические сдвиги, сортировка, последний столбец L и номер строки I;
- `inverse_bwt` – восстановление блока по L и I (n шагов сортировки);
- `to_bits` / `from_bits` – текст ↔ двоичная последовательность (UTF-8);
- режимы: `blocks`, `matrix`, `ascii`, `timing`, `all`.

## Запуск

```bash
python3 lab8/app/main.py blocks   # три блока: имя, фамилия, слово варианта
python3 lab8/app/main.py matrix   # матрица сдвигов слова «молоко»
python3 lab8/app/main.py ascii    # 3 символа -> 48 бит -> BWT -> обратно
python3 lab8/app/main.py timing   # время преобразований от длины блока
```

## Полученные результаты

| Блок | Длина | L | I | Восстановлено |
|---|---|---|---|---|
| Тимофей | 7 | `йфТеимо` | 0 | да |
| Марушко | 7 | `оМшкару` | 0 | да |
| летоисчисление | 14 | `иллнчосеетииес` | 7 | да |

Двоичный блок «лет» (1083, 1077, 1090 → 48 бит) восстановлен без потерь,
I = 40.

Время (среднее по 5 повторам): прямое преобразование растёт почти линейно
(0,03 мс при 100 символах → 1,3 мс при 1600), обратное – квадратично
(1,5 мс → 800 мс), потому что выполняет n сортировок строк.
